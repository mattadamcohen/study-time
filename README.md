# Creature Count

A learning game for ages 6 to 8: maths, logic puzzles, Hebrew (first-grade order, from sounds to stories), English (ABC, phonics, words) and memory games. Correct answers hatch creatures into a trophy cabinet, and finished cabinets unlock family rewards.

Play it at https://mattadamcohen.github.io/study-time/

Progress is saved in the browser on each device. Voice uses the device's built-in Hebrew and English voices (Chrome on Android works best), or recordings made with the 🎙 button in stories.
